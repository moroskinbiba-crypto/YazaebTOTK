TOTK Explorer v3.6.2 audit

Проверено:
- сборка использует libultrahand;
- libultrahand pinned на commit, совпадающий с Tetris Overlay;
- NACP передаётся в elf2nro;
- итоговый .ovl содержит ULTR в последних 4 байтах;
- .ovl начинается с точной копии собранного .nro;
- CI проверяет 152 строки points.csv и допустимые layer значения;
- dmnt:cht инициализируется лениво после GUI;
- переход в persistent HUD не закрывает overlay lifecycle и не рвёт dmnt:cht; обычное закрытие overlay всё ещё освобождает сервис;
- initMemory() очищает частично инициализированный dmnt:cht после ошибки attach/process discovery;
- на поддерживаемых builds Calibration использует только exact Player resolver;
- brute-force heap scan и сохранённый heuristic profile path удалены из runtime;
- старый actor state сбрасывается при смене PID/base;
- fallback scanner удалён из runtime;
- Map HUD не использует недоступные в pinned libultrahand глобальные API;
- verifier синхронизирован с 3.6.2;
- persistent HUD работает внутри одного overlay через `tsl::changeTo<PersistentHudGui>()`, без `setNextOverlay()` и второго `--hud` entrypoint;
- persistent HUD нормализует layer position и обновляет nearby cache вне render callback;
- HUD отдаёт input focus игре через `tsl::hlp::requestForeground(false)` и продолжает обновляться после скрытия меню;
- HUD имеет явное закрытие `L + R + Minus`.

Не проверяется физически:
- реальный runtime на Switch;
- корректность конкретных координатных offsets вне перечисленных builds;
- фактическое отображение overlay в конкретной установленной версии Ultrahand/nx-ovlloader;

CI note: pull-request validation is enabled in the base workflow.
