TOTK Explorer v3.5.0

После загрузки GitHub Actions artifact распакуйте каталог `sd` в корень microSD.

Ожидаемая структура:

sd:/switch/.overlays/TOTK-Explorer-v3.ovl
sd:/switch/totk_explorer/TOTK-Explorer-v3.nro
sd:/switch/totk_explorer/points.csv

Порядок проверки:
1. Запустите TOTK 1.4.0, 1.4.1, 1.4.2 или 1.4.3.
2. Откройте Ultrahand/Tesla.
3. Выберите TOTK Explorer.
4. Для отдельного диагностического запуска можно открыть NRO через Homebrew Menu.
5. Раздел Calibration лениво подключает dmnt:cht; после закрытия overlay он переподключается автоматически при повторном входе.

Логи:
sd:/switch/totk_explorer/log.txt

Overlay read-only: запись в память игры не выполняется.

Choose `Map HUD (persistent)` to launch the persistent HUD mode. The main menu closes, but the map/statistics panel stays over the game.

HUD contents: live player coordinates, world layer, coordinate source, nearby database points and nearest point.

Close HUD with `L + R + Minus`.
