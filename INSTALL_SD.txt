# TOTK Explorer — Stage 1 installation

Из GitHub Actions artifact `TOTK-Explorer-stage1` скопировать:

`sd:/switch/.overlays/TOTK-Explorer.ovl`

На Stage 1 дополнительных файлов на SD-карте не требуется.

Hardware target used for validation:
- Nintendo Switch firmware 22.5.0
- Atmosphere 1.11.2

Проверить:
1. открыть Ultrahand/Tesla;
2. запустить TOTK Explorer;
3. увидеть заголовок `TOTK Explorer / Stage 1`;
4. нажать B;
5. повторить запуск/выход несколько раз;
6. повторить при запущенной игре.

До успешного hardware-теста Stage 1 следующие runtime-слои не добавляются.
